# Wall of Shame and Wall of Fame: design reference

PNG exports of the design boards, so anyone (or any tool) can match the build to the design.
The code is in `src/wall/`. Written notes: `docs/wall-design.md` and `docs/stats-design.md`.

Layout **B** is the one built: the Asha logo and the wall name sit at the top of the card, the link goes in the caption.
The **A** images (title at the top, logo at the bottom) are the option that was not chosen. They are kept for comparison.
